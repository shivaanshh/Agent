Token budget
A soft cap. When it's reached, the remaining steps are skipped and the report is still written.

Give the agent a goal.

It writes a short plan, then works through it one step at a time with live search and page-fetch tools. Each step's result is reviewed before the next one starts. The run ends with a report, and every link the report cites is checked against what the tools actually returned. Failures you inject are handled the same way as real ones.
